OVERVIEW

从 cAMP 响应到受体招募与内化

GCGR 是胰高血糖素（Glucagon）的受体。cAMP Hunter™ GCGR 细胞过表达天然 Gs 耦联的野生型受体，检测激动剂引起的细胞内 cAMP 增加；PathHunter® 产品则分别测量 β-arrestin-1 / -2 招募或内化受体在内体中的定位。

三种检测对应不同生物学事件，适用于受体功能活性和配体药理表征。[1–4]

01

cAMP 累积

cAMP Hunter™ · CHO-K1
检测 GCGR 的 Gs 通路功能响应。

02

β-arrestin-1 / -2 招募

PathHunter® · CHO-K1
检测配体诱导的受体近端招募事件。

03

总受体内化

PathHunter® · HEK 293
检测内化 GCGR 在早期内体中的定位。

ASSAY PRINCIPLE

不同事件，各自对应的检测架构

酶片段互补（EFC）将 β-半乳糖苷酶片段互补转化为化学发光。cAMP 检测采用竞争性免疫检测；招募和内化检测采用各自的标记构建。

cAMP Hunter™ / HitHunter®

GCGR 激活 Gs，促进腺苷酸环化酶（AC）生成 cAMP。细胞 cAMP 与 ED 标记的 cAMP 竞争抗体结合，游离 ED-cAMP 与 EA 互补，底物反应产生光信号。

GCGR 激动 → cAMP ↑ → 发光 ↑

PathHunter® β-Arrestin

GCGR 携带 PK 标签，β-arrestin-1 或 -2 携带 EA 标签（依产品而定）。配体诱导招募使两个酶片段接近并互补，加入底物后产生化学发光。

β-arrestin 招募 ↑ → 发光 ↑

PathHunter® Total GPCR Internalization

GCGR 携带 EA 标签，PK 标签定位于内体。受体内化后在 PK 标记的内体中形成互补，加入底物后产生化学发光。

内化受体与内体标签接近 → 发光 ↑

功能响应、蛋白招募和内体定位分别解释；这些读数不直接测量配体结合亲和力。

PRODUCT PORTFOLIO
